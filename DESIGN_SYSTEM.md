# SINAL. / Visual System 2.0

## Direção de arte
- Plataforma de inteligência editorial premium, não layout de jornal impresso.
- Referência conceitual de interface: clareza, materiais translúcidos, suavidade, profundidade e foco no conteúdo. Sem copiar elementos ou marcas registradas de terceiros.
- Respiro generoso, hierarquia editorial e experiências sem feed infinito.

## Fundamentos de identidade
- Preto tecnológico: `#10131d` / `#11141e`
- Branco de superfície: `#ffffff`
- Fundo neutro: `#f5f5f7`
- Azul de inteligência: `#466efa`
- Violeta de profundidade: `#8268f2`
- Cinza secundário: `#6e7280`
- Títulos: pilha nativa do sistema (`-apple-system`, `Inter`, `Segoe UI`), peso 700–800, tracking negativo.
- Texto: 12–16px com entrelinha ampla. Evitar fontes manuscritas e excesso de letras maiúsculas.
- Bordas: 20–36px, leves, com pouca divisão visual. Sombra muito suave. Cards informativos permanecem legíveis.

## Layout
- Header compacto com símbolo proprietário de sinal, marca SINAL. e assinatura SOMMOS ALTUM.
- Navegação estilo glass com blur e chips para editorias, que permanecem funcionais.
- Hero escuro imersivo com ilustração CSS de uma janela de produto (não é um dashboard real).
- Seções com grandes títulos e grids arejados; capa e Radar Internacional escuros para contraste.
- Observatório com cinco áreas (Creators, Brand + Creators, Rising Brands, Local e RUN).
- Interface mobile com conteúdo empilhado sem rolagem horizontal da página. Navegação por abas continua rolável horizontalmente dentro do próprio componente.

## Funcionalidades preservadas
- Matérias do JSON, busca, categorias, favoritos locais, modal de leitura, modo escuro, arquivo, fontes originais.
- As editorias do observatório continuam aguardando fontes verificadas e integração própria.
- Atualização do site via GitHub Actions permanece independente do envio do ChatGPT.
